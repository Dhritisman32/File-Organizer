# Folder Organizer

Automatically organizes your messy folders into sections like images, pdf, docs, and more. It's just a click to make your folders more organized.

## Features

- Drag and drop
- Dry Scan
- Delete empty folder

## Installation

1. Clone the repository
2. Install dependencies
3. Run the program

Example:

git clone https://github.com/Dhritisman32/File-Organizer ~/project/
cd project
pip install pyqt6
python main.py

## Usage

1. Launch the app.
2. Select a folder.
3. Click "Scan".
4. The files are automatically organized.

## Requirements

- Python 3.11+
- Any os that can run python.
- Required libraries:
  - PyQt6
